# WeedEye

Лёгкий алгоритм выделения и подсчёта сорняков на изображениях.
Курсовая работа по дисциплине «Алгоритмизация и программирование», тема №34:
**индекс ExG, порог Оцу, система непересекающихся множеств (DSU)**.

Пайплайн: фото → ExG (число на пиксель) → порог Оцу (маска «растение / фон»)
→ DSU (склейка соседних пикселей в объекты) → список объектов с координатами
→ сравнение с разметкой.

## Что реализовано сейчас

- `src/weeddet/exg.py`: ExG = 2g − r − b на хроматических координатах, O(N).
- `src/weeddet/otsu.py`: гистограмма и порог Оцу с нуля; поиск порога O(L) за счёт накопленных сумм.
- `src/weeddet/dsu.py`: DSU на списках, флаги сжатия путей и рангов.
- `src/weeddet/components.py`: компоненты связности через DSU (4/8 соседей) и через BFS (эталон).
- `src/weeddet/synthetic.py`: генератор сцен с точной разметкой, воспроизводимый по seed.
- `src/weeddet/baselines.py`: OpenCV и scikit-image, **только для сравнения**.
- `tests/`: 78 тестов; порог Оцу сверяется с OpenCV и scikit-image (допуск ±1), компоненты — со SciPy, OpenCV и BFS.
- `experiments/exp0_segmentation_cwfid.py`: воспроизводимая проверка на CWFID (результат в `results/tables/`).
- `docs/complexity.md`: оценки сложности с обоснованием.

## Предварительные результаты (этап 2)

DSU сверена со SciPy и OpenCV на масках «ExG + Оцу» всех 60 снимков CWFID,
4- и 8-связность (120 прогонов): число компонент и разбиение совпали во всех.
Время одной разметки 1296×966 на чистом Python ≈ 0.26 с (BFS ≈ 0.24 с, то есть
на этих данных разница мала).

**Вывод для следующего этапа:** на реальных масках получается от 327 до 1516
компонент на снимок (в среднем ≈ 770 при 8 соседях). Измерение по всем 60 снимкам:
95.6% компонент меньше 50 пикселей, но вместе они занимают лишь 4.2% площади
растительности; после отсечения по площади ≥ 50 остаётся от 13 до 74 объектов
на снимок (в среднем 34). Без фильтра по площади подсчёт объектов бессмыслен.
Порог 50 пикселей здесь пробный, на этапе 3 его нужно подобрать и обосновать.

## Важные замечания

- **Маски CWFID инвертированы:** в файлах `True` (белый) это почва, растение = `False`.
  README датасета этого не описывает, полярность определена измерением на всех 60 масках.
  Используйте `io_utils.load_cwfid_vegetation_mask`, он делает инверсию.
- ExG выделяет **любую** зелень, а не только сорняки. Отделение сорняков от культуры
  планируется на этапе 4 (размер объекта, положение относительно рядков).
- Цифры выше относятся к сегментации растительности (пиксели), а не к подсчёту сорняков.
  Точность подсчёта объектов появится после этапов 2-5.
